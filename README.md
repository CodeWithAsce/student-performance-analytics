# Student Performance Analytics System

## Project Overview
This project analyzes student marks using Python, Pandas, and NumPy. It calculates total marks, average marks, grades, pass/fail results, class statistics, subject-wise averages, and identifies the top-performing student.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV dataset

## Dataset
The project uses a sample dataset of 15 fictional students. It includes student ID, name, department, marks in Python, Maths and English, and attendance.

## Features
- Calculates total and average marks
- Assigns grades based on average marks
- Determines pass or fail
- Displays total students and class average
- Finds highest and lowest averages
- Calculates subject-wise average marks
- Identifies the top performer

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `main.py` using Python.

## Project Structure
- `main.py` — analysis program
- `students.csv` — sample student dataset
- `requirements.txt` — required Python libraries
- `README.md` — project documentation
